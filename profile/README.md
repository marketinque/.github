# marketinque

**Hands-off marketing. Hands-on control.**

marketinque is a governed AI marketing agent for B2B SaaS founders without a marketing team.
It works through a launch plan in order, drafts across the funnel, and nothing is published,
sent or spent without your say-so: item by item, or by a rule you set per action.

## Use it from Claude Code

The launch plan (350 steps with prerequisites) and an index of 958 places that give a startup
a backlink are served over MCP. Connect once:

```bash
claude mcp add --transport http marketinque https://marketinque.com/mcp
```

Then run `/mcp__marketinque__launch-plan` or `/mcp__marketinque__get-backlinks`. The free tier
needs no account, and the drafting runs on the Claude subscription you already have.

- Listed on the [official MCP registry](https://registry.modelcontextprotocol.io/) as `com.marketinque/launch-plan`
- How it works: [marketinque.com/mcp-for-marketing](https://marketinque.com/mcp-for-marketing)
